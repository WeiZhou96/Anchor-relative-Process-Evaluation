## Scope and integrity

The subset retains the original relative paths below `data/`. It contains 635 selected source files (53,465,929 bytes), including the unchanged data licence. Source data are copied byte-for-byte; no large record is split, compressed further or rewritten. `SHA256SUMS` covers these selected source files plus this README and the filtered provenance ledger; it does not cover the code utilities already present in `data/*.py` and `data/mmau/`.

`REWRITTEN_FILES.tsv` retains only source-release provenance entries for included files. Those rewrites were made by the source release, before this snapshot. Historical CRLF files are explicitly exempted from Git line-ending conversion to preserve recorded hashes. Other text uses LF through `.gitattributes`.

From the repository root:

```bash
python scripts/release/install_data.py verify --data data
export APE_DATA="$PWD/data"
bash figures/run_all.sh
```

On PowerShell, set `$env:APE_DATA = (Resolve-Path data).Path` before invoking individual Python figure/table scripts. The shell entry point requires Bash. Set `APE_DATA` explicitly: the original `run_all.sh` default expects a separate sibling data package. No data installation is required for the `figures/` entry points.

**Do not run `install_data.py install` against this subset.** That command requires the omitted `accident/outputs/answers/` directory and its complete answer index; it may copy partial outputs before failing. `verify` supports this subset without changes.

The numerical preprocessing chain in `figures/run_all.sh` reads stored analysis outputs; successful table generation is not a new evaluation from all model predictions. The subset supports the quantitative figure inputs and the eight numerical/table entry points through `check_reproduce.py`. Original frames are required for the qualitative figures. Figures 1–2 and the revision-history table are not generated by those scripts.

## Excluded data and replication limits

The complete derived-data package will be provided with a DOI archive, subject to author approval and the applicable licences. No DOI or public availability is asserted here.

| Excluded item | Size | Consequence |
|---|---:|---|
| `accident/outputs/r2b/ablations/a1.json` | 128,063,497 bytes | Exceeds the 50 MB per-file limit; no splitting or rewriting. The paper uses the included stored `tableS_A1_reversals.csv`; this subset cannot regenerate that audit table from the raw ablation record. |
| `accident/outputs/r2c/ablations/a1.json` | 129,350,771 bytes | Same limit and archive requirement. |
| Full `accident/outputs/answers/` | approximately 1.2 GB compressed (not present in the local input copy) | Full installer, answer-level re-analyses and full audit recomputation require the archive. |
| Coarse-step answer sets (`__stride2`, `__stride4`; 284 directories) | approximately 2.2 GB uncompressed / 0.5 GB compressed (source-report estimates; absent locally) | Required to recompute the stride axis and relevant gates. Archive arrangement remains to be confirmed. |
| Remaining full-release derived files | Exact local file names and sizes recorded in the preparation manifest outside this repository | Includes aggregate pair records, duplicate pools, full calibration grids, unneeded tables, training predictions/fits and repeated MM-AU evaluation records. |

Raw videos, dataset image frames, model weights/checkpoints, credentials, internal working reports and server-path validation logs are not included. Their availability must not be inferred from the future derived-data archive. Obtain third-party media and pretrained weights under their own terms; the original README/REPLICATION provide source descriptions.

The original README, REPLICATION and licences are retained as supplied. Their full-package sizes, verification results and broad reproduction statements are historical release documentation, not results of validation of this subset. In particular, `report/make_tables.py`, `k_c_verify.py` and all answer-level audit/reanalysis entry points require additional archive inputs. The frozen protocol/preregistration files retain historical model names and one server cache path; these do not supply credentials and await the authors' disclosure decision.
