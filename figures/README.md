# Paper figures and tables

Scripts that regenerate the numeric tables and the quantitative figures of
"Stable correctness after impact: Evaluating collision-type recognition beyond final accuracy"
(main article and Electronic Supplementary Material, ESM) from the derived-data package.
They read stored evaluation records only; no model is trained or evaluated here.

## Quick start

```sh
export APE_DATA=/path/to/data          # derived-data package root (contains accident/ and mmau/)
export APE_FIG_OUT=/path/to/output     # optional; default: ./out
bash run_all.sh                        # PYTHON=python3 by default
```

`run_all.sh` sets `APE_DATA` to `../../data` when it is unset and that folder exists (release layout
`code/figures/` next to `data/`). Outputs go to `$APE_FIG_OUT/internal/` (intermediate records),
`$APE_FIG_OUT/tables/` and `$APE_FIG_OUT/figures/`.

Configuration (all in `paths.py`):

| Variable | Meaning | Default |
|---|---|---|
| `APE_DATA` | derived-data package root | required (`run_all.sh`: `../../data` if present) |
| `APE_ROOT` | code repository root (`ape/`, `report/text/g0_length_shift_stats.json`) | parent of this folder |
| `APE_FIG_OUT` | output root | `./out` |
| `APE_QUAL_FRAMES` | folder with the 18 original dataset frames (qualitative figures only) | unset: qualitative figures skipped |
| `APE_QUAL_SOURCES` | answer-set CSVs for `fig_qualitative_cases.py --verify-sources` (optional) | unset |

Requirements: Python 3.10+, numpy, pandas, matplotlib, scipy (imported by the `ape` package used in
`paper_numbers.py`), Pillow (qualitative figures), OpenCV (frame helper only).
Tested on Linux with Python 3.11, numpy 2.0.1, pandas 3.0.0, matplotlib 3.10.8 (whole chain); the figure
scripts were also run on Windows with matplotlib 3.10.3 and Calibri installed.
Runtime: about 21 s for the whole chain on one CPU core (peak memory about 250 MB).

`*_rows.tex` file with the table body rows exactly as printed; `paper_numbers.json` collects all of them

## Fonts

The figures were designed with Calibri (Windows). `stylelib/` registers Calibri from `C:/Windows/Fonts`
when present; elsewhere matplotlib falls back to DejaVu Sans for text and mathtext. The data, marks and
layout are the same, but text widths differ, so figures made on Linux look slightly different from the
published ones. The resolved font of every run is recorded in `internal/figure_font_log.json`.
On Windows with Calibri the scripts reproduce the published PNG files byte for byte.

## Qualitative figures (Fig. 5 and Fig. S3)

These figures show 18 original frames of the ACCIDENT and MM-AU datasets. The frames are third-party
content and are not included. `qualitative/` holds only derived, non-image records:

- `accident_cases.json`, `mmau_cases.json`: selection rule, candidate strata, the six displayed cases with
  stored predictions, reference-class probabilities, correctness and stable-suffix flags, and the SHA-256
  of the prediction sources (unchanged copies of the authoring files).
- `accident_frames.json`, `mmau_frames.json`: for each frame the clip, offset, decoded timestamp and
  frame index (ACCIDENT) or dataset-relative image path (MM-AU), output file name and SHA-256.
- `accident_videos.json`: dataset-relative path, size and SHA-256 of the three ACCIDENT videos.
- `accident_frame_pixels.json`: SHA-256 of the decoded RGB pixels of the nine ACCIDENT frames
  (independent of the PNG encoder).

Absolute server paths of the authoring records were replaced by dataset-relative paths; nothing else
was changed.

To rebuild the two figures from your own copies of the datasets:

```sh
pip install "opencv-python-headless==4.11.0.86"
python extract_qual_frames.py --accident-root /path/to/ACCIDENT --mmau-root /path/to/MM-AU --out /path/to/frames
APE_QUAL_FRAMES=/path/to/frames APE_DATA=/path/to/data python fig_qualitative_cases.py
```

`extract_qual_frames.py` decodes each ACCIDENT video sequentially with OpenCV, keeps the last decoded
frame at or before the recorded target time and writes it unmodified as PNG; MM-AU frames are copied
byte for byte. Every frame is checked against the recorded SHA-256 (`--dry-run` verifies without
writing). The ACCIDENT frames are reproduced bit for bit with the OpenCV 4.11.0 wheels; newer wheels
(4.13, 5.0) select the same frames but decode pixels that differ by a few grey levels, and the hash
checks of both scripts then fail. `fig_qualitative_cases.py` also re-derives the case read-outs from
the stored predictions and asserts the short notes printed next to each case; `--verify-sources`
repeats the checks against the full prediction arrays. The MM-AU arrays are in `$APE_DATA`; the ACCIDENT
answer-set CSVs are read from `$APE_QUAL_SOURCES`. Two of them can be obtained by decompressing
`accident/outputs/answers/<system>/answers.csv.gz`, but the 0.5-s replay answer set of system B
(`postproc__ema0p7__prefix__gru512__seed20260903__stride2`) is not part of the data package, so the
ACCIDENT part of `--verify-sources` cannot be run from the release alone; its SHA-256 is recorded in
`accident_cases.json`.

## Changes relative to the authoring scripts

Computations are unchanged. The release versions differ only as follows:

- `paths.py` is now a configuration module driven by environment variables (see above); it no longer
  refers to local folders. `figstyle.py` imports the vendored `stylelib/` next to it.
- `build_system_table.py` skips files whose name starts with `_` in `r2b/metrics/<hash>/`: the data
  package ships an aggregate `_pairs.json` next to the 184 per-system records, which the authoring copy
  did not contain.
- `extract_evidence.py` writes the `source` field with `<APE_DATA>`, `<APE_FIG_OUT>` and `<APE_ROOT>`
  placeholders instead of local folder names.
- `fig_qualitative_cases.py` reads its records from `qualitative/`, the frames from `$APE_QUAL_FRAMES`,
  the MM-AU arrays from `$APE_DATA`, and writes its check file to `internal/`.
- Docstrings mention the new locations. In `stylelib/`, one docstring and two comments were edited to
  remove local paths and names; the unused modules `plot_bars.py`, `plot_heatmaps.py`, `plot_lines.py`
  and the font probe script `style_probe_fonts.py` are not included.
- New: `paper_numbers.py`, `extract_qual_frames.py`, `run_all.sh`, this file.

Not included: helpers used only to edit, compile, render or retrieve the manuscript
(`apply_text_edits.py`, `apply_text_edits2.py`, `build_claim_ledger.py`, `build_pdf.py`,
`render_pages.py`, `retrieve_remote.py`), internal design notes, and all dataset frames.
