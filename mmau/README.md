# MM-AU development study

These scripts produced the MM-AU results of the ESM (Table S7, Figs. S2 and S3). The study is a development
study on reused MM-AU development data with the native nine-class task; it is not a confirmatory test. The data
preparation (preflight, decoding, overlap guards, native development manifest) is in `data/mmau/`
(`data/mmau/README.md`); the frame-axis evaluator is `ape/frame_axis.py`.

The model runs (pixel pilot, controls, anchor shift, input stride) need the MM-AU frames and a GPU; they were run
in a separate environment (`mmau/requirements-training.txt`). The APE evaluations and summaries are CPU-only and
start from the predictions in the derived-data package.

## Layout of the outputs

The data package keeps the original output layout: `mmau/deliverables/<study>/...` (predictions `*_predictions.npz`,
cohorts, plans, histories, `ape_evaluation.json`, `RESULTS.json`) and `mmau/evaluation_04/<study>/` (the directories
that were passed to the APE evaluation scripts; their prediction files are byte-identical to those in
`deliverables/`). Several scripts take `--project DIR` and read `DIR/deliverables/...`; use
`--project "$APE_DATA/mmau"` to read the released outputs. Not in the package: the ResNet-18 feature caches
(`features.npz`, `shift_features.npz`, `input_features.npz`), model checkpoints (`*.pt`) and the three raw QA frames;
they are regenerated by the runs below.

Pretrained weights: torchvision ResNet-18 `IMAGENET1K_V1` as a state-dict file (`--weights`), e.g. the file that
`torchvision.models.resnet18(weights="IMAGENET1K_V1")` downloads into `$TORCH_HOME/hub/checkpoints/`. `$APE_MMAU` is
the root of the MM-AU copy (HF `JeffreyChou/MM-AU`, revision `540cb1277cb70e91a7022abe852decb3ee9adb0a`).

## Scripts

| Directory | Step | Command (outputs in a new directory) | Needs |
|---|---|---|---|
| `pixel_pilot_20260920/` | frozen ResNet-18 frame features, prefix-mean and GRU classifiers, 3 seeds | `python pixel_pilot.py --development $APE_DATA/mmau/deliverables/native_task_20260920/outputs/development_verified --root $APE_MMAU --weights RESNET18.pth --out OUT` | frames, GPU |
| | APE evaluation on the frame axis | `python evaluate_pilot.py --directory DIR --vocabulary DIR/vocabulary.json` (DIR as `evaluation_04/native_pixel_pilot_20260920`) | CPU |
| | replay and provenance checks; summary | `verify_pilot_artifacts.py --directory OUT`; `summarize_results.py` (copy next to the outputs; writes `RESULTS.json`) | CPU |
| | overlap evidence of the development guard | `analyze_overlap.py`, `verify_overlap_pixels.py --project P --data-root $APE_MMAU --out OUT` | frames for the pixel check |
| `control_pilot_20260920/` | static-anchor, weighted/unweighted and shuffle controls on the frozen feature cache (18 models) | `python run_controls.py --parent PIXEL_PILOT_OUT --out OUT`; evaluation as above with `evaluate_pilot.py`; `verify_controls.py`, `summarize_controls.py` | features of the pixel pilot, GPU |
| `overlap_dense_20260920/` | dense correspondence of cross-partition candidates | `python dense_overlap.py --project P --root $APE_MMAU --out OUT`; `verify_dense.py`, `summarize_overlap.py`; `select_raw_qa.py` copies three QA frames (needs `APE_MMAU` and `APE_MMAU_PROJECT`) | frames |
| | output-reading sensitivity (300 window/output-grid evaluations) | `python protocol_sensitivity.py --first PIXEL_EVAL_DIR --controls CONTROLS_EVAL_DIR --vocabulary VOCAB --out OUT`; `summarize_sensitivity.py` | CPU |
| `anchor_shift_20260921/` | input start shifted by −4/0/+4 frames (18 frozen models) | `python run_anchor_shift.py --project P --root $APE_MMAU --weights RESNET18.pth --out OUT`; `evaluate_anchor.py --directory OUT --vocabulary VOCAB`; `verify_anchor.py`, `summarize_anchor.py`; weak-candidate overlap `weak_overlap.py`, `verify_weak.py` | frames, checkpoints and features of the pilots, GPU |
| `input_stride_20260921/` | input cadence 2/4/8 frames and the legacy 4+39 schedule on one output grid (72 runs) | `python run_stride.py --project P --root $APE_MMAU --weights RESNET18.pth --out OUT`; `evaluate_stride.py --directory OUT/input --vocabulary VOCAB`; `verify_stride.py`, `summarize_stride.py` | frames, checkpoints and features of the pilots, GPU |

Run the scripts from the repository root with `PYTHONPATH=.` so that `ape` is importable. The `summarize_*.py`
scripts read and write relative to their own location (`Path(__file__).parent`), as in the original output
directories; copy the script into the output directory before running it.

## Seeds and settings

Model seeds 20260920, 20260921, 20260922; 40 epochs, Adam, learning rate 1e-3, weight decay 1e-4, batch 128;
checkpoint by development macro-accuracy at H = 67 frames (see `pilot_plan.json` in each output directory). All
MM-AU evaluations use development clips only.
